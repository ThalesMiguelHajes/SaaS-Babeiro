# SaaS para barbearias e salões de beleza

Projeto de ThalesMiguelHajes para gerenciar estabelecimentos, profissionais, horários, reservas e assinaturas comerciais. Cada estabelecimento terá uma página própria para receber reservas sem exigir cadastro do cliente.

O desenvolvimento começa pelo planejamento técnico da Fase 0. O primeiro marco de implementação será a fundação do aplicativo em Next.js e Supabase.
